Repositório dedicado ao meu estudo do curso **Java e Programação Orientada a Objeto Expert**, com o objetivo de documentar minha evolução em Java e Programação Orientada a Objetos, armazenar exercícios, atividades e desafios realizados ao longo do curso e construir um histórico organizado do meu aprendizado.

## 👨‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas (ADS) na FATEC Indaiatuba** e estou aprofundando meus conhecimentos em programação, com foco no desenvolvimento de aplicações e na construção de uma base sólida em Java.

# 📚 Sobre o curso

O curso **Java e Programação Orientada a Objeto Expert** aborda desde os fundamentos da linguagem Java até conceitos mais avançados de Programação Orientada a Objetos e programação funcional.

A formação é composta por **17 capítulos**, passando por:

* fundamentos da linguagem;
* estruturas de controle;
* métodos e classes;
* Programação Orientada a Objetos;
* construtores e encapsulamento;
* memória, vetores e listas;
* matrizes;
* datas;
* enumerações e composição;
* herança e polimorfismo;
* tratamento de exceções;
* manipulação de arquivos;
* interfaces;
* Generics, Set e Map;
* programação funcional;
* expressões Lambda e Stream.
